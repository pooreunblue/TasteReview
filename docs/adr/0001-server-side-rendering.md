# 0001. 화면을 Thymeleaf 서버 렌더링으로만 제공한다

## 1. 맥락과 문제

맛집 리뷰 서비스는 리뷰 등록·목록·검색·댓글이라는 네 개의 화면 흐름을 필요로 한다.
이 화면을 브라우저에서 조립할지(클라이언트 렌더링), 서버가 완성된 HTML로 내려줄지(서버 렌더링)를 먼저 정해야 한다. 이 선택은 프로젝트 구조 전체와 이후 모든 화면 작업 방식을 결정하므로 나중에 바꾸려면 화면 계층을 다시 만들어야 한다.

## 2. 결정 동인

- (제약) 구현에 허용된 시간이 약 1시간이며 AI가 주도해 작성한다(SRS 5절 C-5).
- (요구사항) JavaScript가 비활성인 브라우저에서도 전 기능이 동작해야 한다(SRS-Q-14).
- (요구사항) 검색 조건이 URL에 남아 공유·새로고침·뒤로가기에서 동일한 결과를 내야 한다(SRS-F-27).
- (비목표) PRD 4절에서 공개 REST API와 SPA 전환을 명시적으로 제외했다.
- (제약) 리뷰 콘텐츠는 검색 엔진에 노출되는 편이 유리하다.

## 3. 검토한 대안

### 대안 A. Thymeleaf 서버 렌더링
컨트롤러가 모델을 채우고 서버에서 HTML을 완성해 내려준다. 상태 변경은 폼 POST 후 리다이렉트.
- 장점: 프로젝트에 이미 의존성이 들어 있고 빌드 도구가 하나로 끝난다. URL이 곧 화면 상태여서 SRS-F-27을 추가 구현 없이 만족한다. JS 없이 동작한다.
- 단점: 상호작용마다 페이지 전체가 다시 로드된다. 폼 검증 피드백이 서버 왕복을 거친다.
- 다시 유력해지는 조건: 해당 없음(현 채택안).

### 대안 B. SPA(React 등) + REST API
백엔드는 JSON API만 제공하고 화면은 브라우저에서 조립한다.
- 장점: 부분 갱신과 풍부한 상호작용에 유리하고, 이후 모바일 앱이 같은 API를 쓸 수 있다.
- 단점: 1시간 안에 프런트엔드 빌드 체계, API 설계, 인증 토큰 처리, 배포 파이프라인을 모두 세우는 것은 현실적이지 않다. PRD가 제외한 REST API를 사실상 도입하게 된다. SEO와 JS 비활성 요구를 별도 렌더링 계층 없이는 만족할 수 없다.
- 다시 유력해지는 조건: 모바일 앱이나 외부 클라이언트가 같은 데이터를 써야 할 때, 또는 화면 내 실시간 갱신이 핵심 가치가 될 때.

### 대안 C. 서버 렌더링 + htmx 부분 갱신
서버 렌더링을 유지하면서 댓글 등록 같은 일부만 부분 교체한다.
- 장점: 전체 리로드를 줄이면서 서버 렌더링의 단순함을 유지한다.
- 단점: 라이브러리 도입과 부분 템플릿 분리가 추가된다. JS 비활성 대비를 위해 두 경로를 모두 유지해야 한다.
- 다시 유력해지는 조건: 댓글이 실제로 활발해져 전체 리로드가 체감 불편으로 보고될 때.

## 4. 결정

**우리는 모든 화면을 Thymeleaf 서버 렌더링으로만 제공하고, 클라이언트 렌더링 프레임워크를 도입하지 않는다.**

가장 무겁게 본 동인은 1시간 제약이다. 이 시간 안에 완결된 기능을 내려면 빌드·배포·인증 경로가 하나여야 한다.
부차적으로, URL이 화면 상태를 그대로 담는 구조가 검색 조건 공유 요구(SRS-F-27)와 검색 엔진 노출 모두를 추가 작업 없이 해결한다.

## 5. 결과

- **얻는 것**: 단일 빌드·단일 배포 산출물. 세션 기반 인증을 그대로 쓸 수 있어 토큰 관리가 필요 없다. JS 비활성 요구가 자연히 충족된다.
- **받아들이는 대가**: 상호작용마다 페이지 전체가 다시 로드된다. 폼 검증 오류를 보여주려면 입력값을 모델에 다시 실어 렌더링해야 한다. 이후 모바일 앱이 생기면 API 계층을 새로 만들어야 한다.
- **후속 작업**: 상태 변경을 POST 후 리다이렉트로 처리하는 규칙을 모든 폼에 적용한다(SRS-F-14, SRS-F-30).
- **재검토 신호**: 외부 클라이언트(모바일 앱 등)가 필요해지거나, 전체 리로드가 사용자 불편으로 실제 보고될 때.

## 6. 준수 확인 방법

템플릿 디렉터리 외부에 클라이언트 빌드 설정이 추가되지 않았는지 확인한다.
JavaScript를 차단한 브라우저로 가입·작성·검색·댓글 시나리오를 완주해 본다(SRS-Q-14).
