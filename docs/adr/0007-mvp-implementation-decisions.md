# 0007. MVP 구현 세부 선택

## 1. 맥락과 문제

PRD·SRS는 외부 동작을 정의하지만, 구현 중 확정해야 할 세부 선택이 남아 있다(지역 목록 초기값,
별점 범위, 삭제 방식, 이미지 처리, 목록 조회 패턴, 환경변수 검증). 사용자는 "묻지 말고 문서로
기록하라"고 지시했고, 도메인·웹·인프라 세 에이전트가 병렬로 구현하므로 계약을 이 문서에 고정한다.

## 2. 결정

| 항목 | 선택 | 사유 |
| --- | --- | --- |
| 지역 후보 목록 | 서울 25개 자치구, `APP_REGIONS`로 변경 가능 | 선택 목록 필요(SRS A-3), 0006으로 외부화 |
| 평점 | 1~5 정수(별 1~5개) | PRD·SRS 전제(SRS A-4), 별 + 숫자 병기 |
| 가입 후 흐름 | 자동 로그인 없이 `/login?registered` 이동 | 세션 조작 회피, 구현 단순 |
| 수정 시 이미지 | 새 이미지 있으면 전체 교체, 없으면 기존 유지 | 등록 규칙 재사용, 수정 단순화 |
| 삭제 | 하드 삭제, 댓글 선삭제 후 리뷰 삭제, 이미지는 cascade | 복구 요구 없음, SRS-F-12 |
| 목록 N+1 방지 | 페이지 조회 + 댓글 수 + 대표 이미지 3쿼리 | SRS-F-22, SRS-Q-3 |
| 대표 이미지 | displayOrder 최소 첫 이미지, 없으면 placeholder | FR-13 |
| 검색 | 가게명·제목·본문 lower LIKE, 지역·별점 등치/범위. 키워드 full scan 수용 | SRS-F-24·F-26·Q-1, 인덱스: created_at·region+rating·store_name |
| 정렬 | latest(기본)/rating, 허용 밖 값은 latest 폴백 | SRS-E-11 |
| 이미지 검증 | multipart 5MB/20MB + 유효성 검증(개수·형식·크기) | SRS-F-17, SRS-E-6 |
| 이미지 저장 | DB BLOB(0004 재확인) | Render 휘발성 FS(SRS C-4) |
| 댓글 삭제 | 작성자 본인만, 이미 삭제된 댓글은 무오류 무시 | SRS-F-32, SRS-E-8 |
| 삭제 확인 | 확인 화면(GET) 후 POST 확정 | SRS-F-13, PRG로 CSRF 자연 적용 |
| 필수 환경변수 | prod 활성 시 기동 직전 검증, 누락 변수명 명시 후 실패 | SRS-F-35 |
| 로그인 | formLogin 세션 기반, CSRF 유지(비활성 금지) | ADR 0001, NFR-5 |
| 통합 테스트 | Testcontainers PostgreSQL(postgres:17-alpine) | 0003, 로컬 Docker |

## 3. 결과

- **얻는 것**: 미확정 값을 코드에서 분리하고 에이전트 계약을 문서로 고정. 대부분 0006 환경변수 뒤에
  있어 재배포 없이 조정 가능.
- **받아들이는 대가**: 관리 항목 증가. 키워드 full scan은 리뷰 1만 건 시점에 재측정 필요(PRD 11절).
  이미지 DB 저장은 Neon 용량 한도에 닿는 임시 구조(0004).
- **후속 작업**: SRS 12절에 0007 해소 항목 표시, SRS 7.3과 application.yaml 동기화.
- **재검토 신호**: 지역 체계 확장, 검색 지연, 이미지 저장 방식 변경(0004 재검토 신호).

## 4. 준수 확인 방법

application.yaml과 SRS 7.3 표의 값이 일치하는지 검사한다. 통합 테스트와 EnvGuard 테스트로
필터·정렬·삭제·환경변수 검증이 지켜지는지 확인한다(SRS-F-35).
