# 0001. 맛집 리뷰 서비스 MVP 소프트웨어 요구사항 명세서

## 1. 목적과 범위

이 문서는 PRD `0001 맛집 리뷰 서비스 MVP`가 정의한 제품을 구현 가능한 수준으로 명세한다.
대상 범위는 회원 가입·로그인, 리뷰 등록·수정·삭제, 리뷰 사진, 목록·상세, 검색·필터, 댓글이며, 여기에 Render 배포와 Neon PostgreSQL 연결, 컨테이너 이미지 구성이 더해진다.

PRD 4절의 비목표(가게 마스터 데이터, 지도, 대댓글·좋아요, 신고·관리자 화면, 소셜 로그인·이메일 인증, 공개 REST API, 알림)는 이 명세에서도 범위 밖이다.
배포·설정 관련 요구사항(6.7, 9.3, 9.4)은 PRD에 근거가 없고 사용자의 구현 지시에서 비롯된 것이므로, PRD 갱신 전까지는 출처가 다르다는 점을 11절에 표시한다.

| 지역 | 리뷰를 분류하는 행정 구역 단위 값. 자유 입력이 아니라 설정으로 주어진 목록에서 선택한다 |

## 4. 시스템 개요

시스템은 단일 Spring Boot 애플리케이션이며 서버 렌더링 화면만 제공한다. 외부와의 접점은 다음과 같다.

| 액터 / 외부 요소 | 관계 |
| --- | --- |
| 방문자(비로그인) | 목록·상세·검색 화면을 조회한다 |
| 회원(로그인) | 리뷰와 댓글을 등록·수정·삭제한다 |
| Neon PostgreSQL | 회원·리뷰·사진·댓글 데이터를 저장하는 유일한 영속 저장소 |
| Render | 컨테이너 이미지를 실행하고 `PORT`와 환경변수를 주입하며 헬스 체크로 기동을 판단한다 |
| 브라우저 | HTML 폼 전송과 이미지 요청만으로 모든 기능을 사용한다 |

## 5. 가정과 제약

**제약**

- C-1. 런타임은 Java 17, Spring Boot 4.1.1, Thymeleaf, Gradle, Lombok이다.
- C-2. 화면은 서버 렌더링으로만 제공한다. 상태 변경은 POST 요청 후 리다이렉트로 관찰된다.
- C-3. 배포 대상은 Render이며 애플리케이션은 컨테이너 이미지로 빌드·실행된다.
- C-4. 영속 저장소는 Neon PostgreSQL 하나뿐이다. 애플리케이션 인스턴스의 로컬 파일시스템은 휘발성이므로 어떤 사용자 데이터도 저장하지 않는다.
- C-5. 구현에 허용된 시간은 약 1시간이다. 요구사항의 우선순위 `必`는 이 시간 안에 반드시 완료해야 하고, `選`은 시간이 부족하면 제외하고 미완료로 보고한다.
- C-6. 값이 바뀔 수 있는 모든 설정은 환경변수로 주입한다. 소스 코드와 템플릿에 접속 정보·크기 제한·페이지 크기·지역 목록 같은 값을 직접 적지 않는다.

**가정** (틀리면 영향받는 요구사항을 함께 적는다)

- A-1. Render와 Neon 모두 무료 플랜을 사용한다. 유료 플랜이면 SRS-Q-1의 콜드 스타트 예외와 SRS-Q-5의 용량 상한이 달라진다.
- A-2. 스키마는 JPA 자동 생성(`ddl-auto=update`)으로 만든다. 마이그레이션 도구를 도입하면 SRS-F-38과 SRS-Q-9가 달라진다.
- A-3. 지역 목록은 설정으로 주입하며 초기값은 서울 자치구 수준으로 둔다. 분류 체계가 2단계(시/도 + 시군구)로 확정되면 SRS-F-8, SRS-F-25, 데이터 요구사항이 달라진다.
- A-4. 별점은 1~5 정수다. 0.5 단위를 도입하면 SRS-F-8과 SRS-F-25가 달라진다.
- A-5. 사진은 Neon PostgreSQL에 바이너리로 저장한다. 외부 오브젝트 스토리지로 전환하면 6.3 전체와 SRS-Q-5가 달라진다.
- A-6. 동시 접속 사용자는 10명 이하다. 그 이상이면 SRS-Q-1의 측정 조건과 커넥션 풀 크기를 재검토해야 한다.

검증 방법은 T(시험), I(검사), D(시연), A(분석)로 표기한다.

### 7.2 저장소 및 플랫폼 인터페이스

- **Neon PostgreSQL**: JDBC로 접속하며 접속 문자열·사용자·비밀번호는 환경변수로 주입한다. Neon은 TLS 연결만 허용하므로 접속 문자열에 `sslmode=require`가 포함되어야 한다.
- **커넥션 풀**: Neon 무료 플랜의 동시 연결 한도와 자동 유휴 정지를 고려해 최대 풀 크기를 작게(기본 5) 두고 환경변수로 조정 가능해야 한다. 풀 크기를 코드에 고정하지 않는다.
- **Render**: 컨테이너 이미지를 실행하고 `PORT`를 주입한다. 헬스 체크 경로는 7.1의 헬스 체크 엔드포인트를 사용한다.
- **컨테이너 이미지**: 빌드와 실행을 분리한 다단계 Dockerfile로 작성하고, 실행 단계는 JRE만 포함하며 루트가 아닌 사용자로 프로세스를 실행한다. 빌드 결과는 어떤 환경변수도 이미지에 굽지 않는다.
- **로컬 파일시스템**: 임시 파일 외 용도로 사용하지 않는다. 컨테이너 재시작 시 소실되어도 기능에 영향이 없어야 한다.

### 7.3 설정 항목

모든 항목은 환경변수로 주입하며, 애플리케이션 설정 파일에서 `${환경변수:기본값}` 형태로 참조한다. 기본값이 없는 항목은 필수이며 누락 시 SRS-F-35에 따라 기동을 중단한다.

| 엔티티 | 속성 | 제약 | 보존 정책 |

인덱스는 최소한 다음을 둔다: 리뷰의 작성 시각(목록 정렬), 리뷰의 지역과 별점(필터), 댓글의 소속 리뷰(상세 조회).
사진 바이너리는 리뷰 목록·검색 조회 시 함께 읽히지 않아야 한다. 목록 응답에 바이너리가 실리면 SRS-Q-1을 만족할 수 없다.
